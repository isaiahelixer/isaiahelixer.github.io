# Hardware Improvements for Version 2.0

Based on the behavior of the current subsystem, a big 2.0 redesign should be on strengthening the analog signal chain, improving power management, and expanding testability features. The most important update involves reworking the analog front end for the DIY capacitive moisture sensor. At the moment, the signal increases in peak-to-peak amplitude rather than changing in period post and pre op-amp, indicating that the microcontroller is receiving a AC type waveform from the capacitve sensor. To correct this I think the operational amplifier should be redesigned to operate as an active peak detector or precision rectifier. Converting the sensor’s AC amplitude into a stable DC level will allow the PIC18F57Q43’s ADC to interpret the data more accurately. With this change I would also add a properly designed active low-pass filter at the output will further stabilize the signal by removing high-frequency noise before it reaches the microcontroller.

Power management and system feedback should also get updated for Version 2.0. The existing Power On LED is tied only to the main +5V rail, so when the PIC18F57Q43 is switched to the programmer line there is no failsafe when power is feed from the PIC to the rest of the board. To provide consistent visual feedback during development and testing, a diode OR-ing circuit and a dedicated GPIO-controlled LED should be added to show different power states. This would help show a clear status indication regardless of whether it is powered by the programmer, 5V supply, or in a bad case of both. Another minor change could be replacing the LM7805 linear regulator with a switching regulator will improve efficiency and reduce heat generation when stepping the 9V input down to 5V.

Lastly, the new design should have improved debugging access, the debug pins should be mapped to more unique pins on the PIC18F57Q43 such as PWM, ADC, DAC, etc... The current board also has very limited grounding test points which makes it difficult to attach oscilloscope probes without introducing noise. I also think Implementing a star-ground layout will also help by separating the noisy digital return paths of the PIC from the sensitive analog ground of the sensor circuitry. This prevents digital switching noise from interfering with the improved amplification and filtering creating a better cleaner and reliable signal chain overall.
